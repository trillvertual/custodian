# Основа frontend

Интерфейс перенесён из [mishkatik/infra-billing](https://github.com/mishkatik/infra-billing/tree/9a91a11d0ab662908e6ee9488797a9569aa2be43), commit `9a91a11d0ab662908e6ee9488797a9569aa2be43`, версия source `0.48.0`.

[infra-billing-source.json](infra-billing-source.json) фиксирует исходные пути, целевые файлы и SHA-256 исходников до адаптации. Форматирование приведено к Prettier проекта.

Прямо перенесены `button`, `input`, `table`, `card`, `dialog`, `command`, `select`, `tooltip`, `checkbox`, `PageHeader`, `CardHeadRow`, `pageChrome`, `utils`, CSS темы и мобильных полей. Для совместимости заменены алиасы импортов и агрегированные импорты Radix на отдельные пакеты. Тексты закрытия диалога переведены на русский.

`layout/AppLayout.tsx` адаптирует `layout/AppLayout.tsx` и `layout/SidebarParts.tsx` source: боковая панель 256px, header 64px, portal-слоты заголовка и действий, отступы контента 32px, обычный wordmark, строки навигации 32px, тонкие Tabler-значки, пользователь и переключатель темы внизу. Mobile drawer сохраняет доступный Radix modal с возвратом фокуса.

`components/search-palette.tsx` адаптирует `components/CommandPalette.tsx`: Ctrl/Cmd+K, поиск по метаданным расшифрованных записей, выбор результата с клавиатуры. Вместо провайдеров и биллинговых сущностей используются записи хранилища. Секреты не включаются в поиск или список результатов.

Таблица записей, команда и журнал используют перенесённые Card/Table/CardHeadRow. Просмотр записи использует перенесённый Dialog, как detail-формы source. Вход, первичная настройка, редактор и настройки используют геометрию, поля, шрифт и поверхности source.

В карточке записи название и действия собраны в шапке, значения выровнены, папка и теги сгруппированы, действие корзины подписано. Тип записи выбирается через source Select. Папки и теги используют поисковый Popover с созданием вариантов и удалением выбранных тегов. Checkbox и подсказки кнопок используют source Radix primitives; сообщения валидации форм выводятся в интерфейсе. Подсказки поддерживают hover и фокус, списки - клавиатуру, touch и Escape с возвратом фокуса. Всплывающие элементы используют действующие цвета и motion tokens Custodian.

Шрифты source: Golos Text 400/500 и IBM Plex Mono 400, поставляются локально через Fontsource. Базовые light/dark tokens, размеры и слабые shadows находятся в `apps/web/src/infra-theme.css`. Согласованная палитра #790D16 / #E5D3AF / #F5EFE1 / #AEC4D4 адаптирована отдельным слоем `styles.css`: бордовые действия в light, кремовый canvas, светлая поверхность sidebar/card, бежевые действия в dark, синий активный пункт. Геометрия и типографика следуют source.

`components/rwp-promo.tsx`, `ui/popover.tsx` и логотип RWP перенесены из source по отдельному запросу пользователя. Купон расположен в общем sidebar и на экранах входа, настройки и восстановления. Скидка заменена на 10%, промокод на `LAZYBAGEL`; копирование сообщает об успехе только после успешного обращения к clipboard. Тот же промокод указан в README.

Клиентская криптография, сервер, права участников, OAuth/Passkey и rescue CLI принадлежат Custodian. Биллинговые API и данные исходного приложения в продукт не перенесены.
