# Custodian v0.5.2

Обновление безопасности контейнера, проверок и зависимостей. Рекомендуется пользователям v0.5.1 и более ранних версий.

- **Runtime-образ:** при сборке обновляются пакеты Debian, удалены ненужные npm/npx/corepack. Это устраняет исправимые HIGH-находки APT и встроенного npm в прежнем образе. Сервер и rescue запускаются через `node`; стандартный Docker Compose сохраняется.
- **Зависимости:** Fastify 5.12.8 и Undici 8.12.4 включают исправления, найденные Snyk. React и React DOM обновлены совместно до 19.3.1. Vitest 5.1.0 и Playwright 1.65.0 используются для проверок.
- **Автопроверки:** типизированный ESLint с изолированным поддерживаемым компилятором; Snyk; Trivy для собранного и опубликованного image digest; ежедневная проверка опубликованной версии. Полные SARIF сохраняются в GitHub Code Scanning. Greptile выполняет ревью, What The Diff создаёт summary. [Область и настройка](https://github.com/trillvertual/custodian/blob/v0.5.2/docs/AUTOMATED-REVIEW.md).
- **Сопровождение:** CodeQL 4.39.3 и Docker login action 4.8.0 закреплены полными SHA. React/renderer сгруппированы в Dependabot. CI и Docker build отклоняют зависимости с несовместимым Node через `--engine-strict`.

Поддерживаемый runtime остаётся **Node 22**. QR-библиотека сохранена на совместимой ветке: предложенная версия `@zxing/browser 0.2.1` требует `@zxing/library 0.23`, у которой минимум Node 24. Это обновление отложено до отдельного перехода runtime; текущие QR image/paste/camera сценарии проверяются.

## Обновление

Новых миграций БД нет, актуальна схема 4. Форматы записей и rescue-ключей сохраняются, повторная настройка Passkey или доверия браузеру не требуется.

Сохраните backup БД и конфигурацию перед обновлением. [Установка, обновление и откат](https://github.com/trillvertual/custodian/blob/v0.5.2/docs/OPERATIONS.md). В контейнере используйте rescue командой `node packages/rescue/dist/index.js ...`; npm-команды предназначены для checkout/архива на хосте.

Образ: `ghcr.io/trillvertual/custodian-app:v0.5.2`, **linux/amd64**. Точный digest записан в `release.json`. Публикация не обновляет работающие установки автоматически.

## Файлы и проверки

- `custodian-0.5.2-source.tar.gz` – исходники тега, включая dev-инструменты и lockfile.
- `custodian-0.5.2-runtime.tar.gz` – сборки web/server/rescue и документация; после распаковки `npm ci --omit=dev`. Node.js >=22.12.0.
- `custodian-0.5.2-sbom.cdx.json` – CycloneDX inventory production-зависимостей.
- `release.json` – версия, revision и image digest.
- `SHA256SUMS` – проверка через `sha256sum --check SHA256SUMS`.

Упаковщик до публикации связывает source-архив с Git-маркером commit, а runtime-архив – с `build-info.json` (версия и packaging revision). 17 автоматических сценариев verifier выполняются в обычном наборе тестов до публикации.

После публикации отдельный read-only job анонимно скачивает пять assets, проверяет SHA-256, revision и OCI digest/labels/attestation, затем повторно сканирует фактически опубликованные архивы на секреты. Его можно повторить без замены релиза. Команда `npm run release:verify` доступна для независимой проверки.

Перед публикацией обязательны TypeScript, ESLint и lint smoke, тесты приложения, Chromium desktop/mobile и axe, Docker/PostgreSQL 18/rescue, аудит зависимостей, сканирование секретов и проверка точного опубликованного образа. Гейт Trivy блокирует исправимые HIGH/CRITICAL; находки без доступного исправления остаются в полном отчёте. Автоматические проверки не заменяют независимый pentest или криптографический аудит.
