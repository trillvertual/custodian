# Custodian v0.3.0

Три улучшения для ежедневной работы с доступами VPN-инфраструктуры.

- **Действия из поиска.** `Ctrl/⌘+K` открывает поиск. Выберите результат стрелками: `Enter` открывает запись, `Ctrl/⌘+Enter` копирует основной секрет, `Alt+Enter` – логин, `Ctrl/⌘+Shift+Enter` – текущий код 2FA. Те же действия доступны кнопками, включая мобильный интерфейс. Секреты остаются скрытыми; копирование проходит проверку доступа и аудит.
- **Шаблоны.** SSH-сервер, Remnawave, Telegram-бот, PostgreSQL, аккаунт хостера и API-токен. Шаблон задаёт тип, папку, теги и дополнительные поля. Замена введённых данных требует подтверждения.
- **Создать похожую.** Из карточки создаётся отдельная запись с прежним типом, папкой, тегами и названиями полей. Адрес, логин, пароль/ключ/токен, заметка, 2FA и все значения дополнительных полей пустые. Исходная запись и история не меняются.

Пустой поиск показывает недавние записи. В браузере сохраняются только ID, отдельно для каждого пользователя и хранилища. Секреты, названия и ключи шифрования в эту историю не записываются.

## Обновление

Схема БД, формат шифрования, аккаунты и rescue-ключи совместимы с v0.2.0. Новых миграций и зависимостей нет. Перед обновлением сохраните backup БД и конфигурацию; [инструкция](https://github.com/trillvertual/custodian/blob/v0.3.0/docs/OPERATIONS.md#обновление).

Образ: `ghcr.io/trillvertual/custodian-app:v0.3.0`, **linux/amd64**. Точный digest указан в `release.json`. Выпуск релиза не обновляет работающие установки автоматически.

## Файлы

- `custodian-0.3.0-source.tar.gz` – исходники из commit тега.
- `custodian-0.3.0-runtime.tar.gz` – собранные web/server/rescue и документация. После распаковки выполните `npm ci --omit=dev`; требуется Node.js >=22.12.0.
- `custodian-0.3.0-sbom.cdx.json` – production npm-зависимости.
- `release.json` – версия, commit, Node.js и digest образа.
- `SHA256SUMS` – проверка через `sha256sum --check SHA256SUMS`.

Публикация проходит CI: типы, форматирование, unit/API/crypto, Chromium desktop/mobile, axe, сканирование секретов, Docker/PostgreSQL 18, распакованный runtime и опубликованный образ по точному digest. Независимый аудит криптографии и физические Passkey-устройства этими проверками не покрываются. [Модель безопасности](https://github.com/trillvertual/custodian/blob/v0.3.0/docs/SECURITY.md).
