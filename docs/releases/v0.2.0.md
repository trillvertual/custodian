# Custodian v0.2.0

Первый публичный релиз командного менеджера доступов под MIT.

Custodian хранит логины, пароли, API-токены, SSH-ключи, заметки и TOTP. Одна установка обслуживает одну команду; владелец приглашает администраторов и выдаёт ключи доступа. Данные шифруются в браузере. Для восстановления доступны rescue-ключ и CLI.

## Изменения

- Единый логотип в интерфейсе, favicon и README, включая вариант для тёмной темы.
- Защита от отложенного раскрытия и копирования секретов после закрытия карточки или блокировки хранилища.
- Обработка некорректных TOTP-секретов, устаревших ответов API и повторной отправки форм.
- Подключение Passkey прерывается при блокировке; временные копии ключей очищаются до сетевой отправки.
- Более точные тексты, доступные подписи и подсказки, сообщения об ошибках сети и копирования.
- Brotli/gzip для статических файлов и доступная с клавиатуры прокрутка таблиц.
- Проверки desktop/mobile, обеих тем, клавиатуры, touch, reduced motion, доступности, секретов и зависимостей.
- Новый публичный репозиторий начинается с проверенного снимка кода, без прежней истории Git.

## Совместимость

Новых миграций БД и изменений формата зашифрованных данных нет. Существующие аккаунты, записи и rescue-ключи совместимы. Блокировка по бездействию и скрытию вкладки отсутствует; ручная блокировка очищает открытые ключи и интерфейс.

Перед обновлением сохраните backup БД и конфигурацию. Следуйте [инструкции обновления](https://github.com/trillvertual/custodian/blob/v0.2.0/docs/OPERATIONS.md#обновление). Публикация релиза не обновляет работающие установки автоматически.

Образ: `ghcr.io/trillvertual/custodian-app:v0.2.0`, платформа **linux/amd64**. Для точного закрепления версии используйте digest из `release.json`. Также доступна сборка из исходников через Docker Compose.

## Файлы релиза

- `custodian-0.2.0-source.tar.gz`: исходники из commit тега.
- `custodian-0.2.0-runtime.tar.gz`: готовые web/server/rescue builds, manifests, MIT и документация. После распаковки выполните `npm ci --omit=dev`; runtime требует Node.js >=22.12.0.
- `custodian-0.2.0-sbom.cdx.json`: CycloneDX inventory production npm-зависимостей.
- `release.json`: версия, commit, Node.js сборки и digest образа.
- `SHA256SUMS`: проверка files через `sha256sum --check SHA256SUMS`.

CI проверяет типы, форматирование, unit/API/crypto тесты, Chromium desktop/mobile, доступность и runtime-архив. Docker/PostgreSQL 18 и опубликованный образ проверяются отдельно по точному digest. Файлы и содержимое архивов проходят проверку секретов перед загрузкой. Docker manifest содержит SBOM и provenance.

Независимый аудит криптографии и проверка на физических Passkey-устройствах не заменяются автоматическими тестами. [Модель безопасности](https://github.com/trillvertual/custodian/blob/v0.2.0/docs/SECURITY.md), [результаты проверки публикации](https://github.com/trillvertual/custodian/blob/v0.2.0/docs/PUBLICATION-AUDIT.md).
