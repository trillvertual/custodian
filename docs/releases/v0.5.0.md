# Custodian v0.5.0

- **Passkey из Bitwarden без повторного пароля:** после однократного открытия паролем и включения «Доверять этому браузеру» следующий вход тем же Passkey сразу открывает записи. Поддерживается Passkey без PRF; прямое открытие с PRF сохраняется.
- **Управление доверием:** настройка в форме разблокировки или в настройках аккаунта, названия и список браузеров, отзыв доступа. Для другого или очищенного профиля нужна повторная настройка. Пароль остаётся резервным способом.
- **Менеджеры паролей:** корректная разметка аккаунта и служебных полей, логин при разблокировке и смене пароля. Приглашение отображается выделяемым текстом с копированием, без HTML input. Сопоставление разных поддоменов настраивается в самом Bitwarden через Host.
- **Диалоги:** длинные кнопки полностью видны, действия переносятся по доступной ширине. Изменение размеров окна не выталкивает диалог за экран. Исправлена гонка Ctrl+K после закрытия редактора; анимации открытия и закрытия сохранены.

## Как включить вход без повторного пароля

После обновления войдите через Passkey, один раз введите пароль и включите **«Доверять этому браузеру»**. На уже открытом хранилище: **Настройки → Способы входа → Доверенные браузеры → Настроить**.

Опция сохраняет неэкспортируемый WebCrypto-ключ в профиле браузера; сервер хранит только зашифрованную оболочку личного ключа. Её выдача требует свежего подтверждения конкретного Passkey и одноразового права. Используйте режим только на личном устройстве. Подменённый код сайта может использовать локальный ключ, поэтому этот режим отличается от PRF по защите от такого сервера. [Настройка](https://github.com/trillvertual/custodian/blob/v0.5.0/docs/PASSWORD-MANAGERS.md), [модель безопасности](https://github.com/trillvertual/custodian/blob/v0.5.0/docs/SECURITY.md#доверенный-браузер-без-prf).

## Обновление

Миграция **4** добавляет таблицу доверенных браузеров, credential ID сессии и одноразовое право открытия. Выполняется автоматически. Форматы зашифрованных записей и rescue-ключей не изменены; резервная копия сервера не содержит локальные ключи браузеров. Перед обновлением сохраните backup БД и конфигурацию. [Установка, обновление и откат](https://github.com/trillvertual/custodian/blob/v0.5.0/docs/OPERATIONS.md).

Образ: `ghcr.io/trillvertual/custodian-app:v0.5.0`, **linux/amd64**. Точный digest указан в `release.json`. Работающие установки автоматически не обновляются.

## Файлы и проверки

- `custodian-0.5.0-source.tar.gz` – исходники тега.
- `custodian-0.5.0-runtime.tar.gz` – сборки web/server/rescue и документация; после распаковки `npm ci --omit=dev`. Node.js >=22.12.0.
- `custodian-0.5.0-sbom.cdx.json` – CycloneDX inventory production-зависимостей.
- `release.json` – версия, revision и image digest.
- `SHA256SUMS` – проверка через `sha256sum --check SHA256SUMS`.

88 тестов, 34 Chromium desktop/mobile сценария, проверки axe, TypeScript, формата, зависимостей, секретов, Docker/PostgreSQL 18 и опубликованного образа по точному digest обязательны перед публикацией. В сценариях Passkey используется настоящий браузерный WebAuthn с виртуальным authenticator без PRF; реальный аккаунт Bitwarden, физические устройства и независимый криптографический аудит ими не покрываются.
