# Custodian v0.5.4

Плановое обновление зависимостей после разбора пяти PR Dependabot и результатов автоматических проверок.

- **Radix Slot 1.5.0:** исправления компонента, используемого кнопками и другими элементами с `asChild`, и совместимость optional types с TypeScript. React/renderer остаются на 19.3.1.
- **Tabler Icons React 3.51.0:** обновлена библиотека иконок.
- **PGlite 0.5.16 и fake-indexeddb 6.2.8:** исправления тестовых баз и IndexedDB, включая завершение транзакций и работу ключей.
- **jsdom 31.0.0:** обновлено DOM-окружение тестов. Изменения CSS, парсинга и optional canvas backend проверяются на используемых проектом сценариях. Нативный canvas backend не добавляется; QR/camera сценарии выполняются настоящим Chromium.

Для разработки используйте Node из `.node-version` (22.23.3): jsdom 31 требует Node `^22.22.2 || ^24.15.0 || >=26`. Production runtime без dev-зависимостей сохраняет минимум Node 22.12.0.

## Совместимость и обновление

Новых миграций нет, актуальна схема БД 4. Форматы записей и rescue-ключей, Passkey и доверенные браузеры сохраняются. PGlite – тестовый инструмент; production по-прежнему использует PostgreSQL 18.

Перед обновлением сохраните backup БД и конфигурацию. [Установка, обновление и откат](https://github.com/trillvertual/custodian/blob/v0.5.4/docs/OPERATIONS.md).

Образ: `ghcr.io/trillvertual/custodian-app:v0.5.4`, **linux/amd64**. Точный digest записан в `release.json`. Публикация не обновляет работающие установки автоматически.

## Файлы и проверки

- `custodian-0.5.4-source.tar.gz` – исходники тега и lockfile.
- `custodian-0.5.4-runtime.tar.gz` – сборки web/server/rescue и документация; после распаковки `npm ci --omit=dev`.
- `custodian-0.5.4-sbom.cdx.json` – CycloneDX inventory production-зависимостей.
- `release.json` – версия, revision и image digest.
- `SHA256SUMS` – проверка через `sha256sum --check SHA256SUMS`.

Сохраняются проверки полноты SBOM по lockfile, production-графа, source/runtime revision и совпадения lockfiles архивов. Проверка опубликованного релиза анонимно скачивает все пять файлов и сверяет OCI digest/labels/attestation до сохранения данных.

Обязательны TypeScript, ESLint/lint smoke, тесты приложения, Chromium desktop/mobile и axe, Docker/PostgreSQL 18/rescue, аудит зависимостей, Gitleaks и Trivy точного image digest. Исправимые HIGH/CRITICAL блокируют выпуск; находки без доступного исправления сохраняются в полном отчёте. Автоматические проверки не заменяют независимый криптографический аудит.
