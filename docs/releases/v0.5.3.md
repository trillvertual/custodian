# Custodian v0.5.3

Исправление ведомости production-зависимостей (SBOM). В v0.5.2 экспорт `npm sbom --omit=dev` пропускал пакеты, нужные одновременно приложению и корневым тестам, включая Fastify, React и @noble/hashes. Эти пакеты присутствовали в приложении; ошибка затрагивала ведомость для аудита.

- Упаковщик получает полный CycloneDX inventory и отбирает установленные production-пакеты по независимому дереву `npm ls --omit=dev --all --json --long` с разрешением workspace-ссылок.
- Повторяющиеся package refs объединяются с сохранением путей установки, hashes и лицензий. Dev-only компоненты удаляются; граф строится по production-связям независимого дерева npm, поэтому корневые dev-связи между production-пакетами также исключаются. Лицензии из поздней duplicate-записи сохраняются; противоречащие лицензии или hashes останавливают экспорт.
- Перед публикацией проверяются обязательные production-пакеты по lockfile, версии, package identities, уникальность refs, целостность и связность графа. Неустановленные optional platform-пакеты допускаются.
- Анонимный `release:verify` повторяет проверку полноты по lockfile скачанного source-архива и требует совпадения source/runtime lockfiles. Неполный SBOM, в том числе из v0.5.2, отклоняется до сохранения скачанных файлов.

Добавлены регрессионные сценарии для совместных runtime/dev-зависимостей, workspace-ссылок, duplicate refs, отсутствующих пакетов и повреждённого графа, а также проверка реального установленного дерева. Сохраняются проверки SHA-256, встроенных revision обоих архивов и OCI digest/labels/attestation.

## Обновление

Node 22, схема БД 4, форматы записей и rescue сохраняются. Новых миграций и повторной настройки Passkey нет. Обновление включает исправления безопасности v0.5.2. [Установка, backup и обновление](https://github.com/trillvertual/custodian/blob/v0.5.3/docs/OPERATIONS.md).

Образ: `ghcr.io/trillvertual/custodian-app:v0.5.3`, **linux/amd64**. Точный digest – в `release.json`. Публикация не обновляет работающие установки автоматически.

## Файлы

- `custodian-0.5.3-source.tar.gz` – исходники тега и lockfile.
- `custodian-0.5.3-runtime.tar.gz` – сборки web/server/rescue и документация; после распаковки `npm ci --omit=dev`.
- `custodian-0.5.3-sbom.cdx.json` – исправленный CycloneDX inventory production-зависимостей.
- `release.json` – версия, revision и image digest.
- `SHA256SUMS` – проверка через `sha256sum --check SHA256SUMS`.

Опубликованные теги и файлы v0.5.2 сохраняются. Независимая проверка: `npm run release:verify -- --tag v0.5.3 --revision <commit> --latest --output <empty-directory>`.
